# Selaras Wedding Template

Template landing page untuk website wedding planner / perusahaan jasa pernikahan dengan konsep elegan, hangat, dan modern. Project ini masih dalam tahap pengembangan, dibuat menggunakan HTML, CSS, dan JavaScript dengan pendekatan desain yang responsif.

## Deskripsi

Proyek ini berfokus pada tampilan landing page untuk brand wedding organizer atau planner. Fitur utama mencakup:

- Hero section yang kuat dan elegan
- Informasi tentang brand / perusahaan
- Layanan wedding planner
- Proses kerja
- Paket layanan
- Galeri foto
- Testimoni klien
- Section kontak / konsultasi
- Layout responsif untuk desktop dan mobile

## Teknologi yang Digunakan

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- Google Fonts

## Cara Menjalankan

1. Clone repository

```bash
git clone https://github.com/AndreanKun3/template_wedding.git
```

2. Masuk ke folder project

```bash
cd template_wedding
```

3. Buka file `index.html` di browser, atau gunakan live preview dari editor seperti VS Code dengan extension Live Server.

## Cara Kustomisasi

### Mengubah konten
Edit file `index.html` untuk mengganti:

- nama brand
- text hero
- layanan
- harga paket
- kontak dan email
- testimoni
- data perusahaan

### Mengubah tampilan
Ubah file CSS di folder `assets/css/` sesuai kebutuhan visual, seperti:

- warna utama
- jenis font
- spacing
- section background
- tombol dan card styling

### Mengubah interaksi
Jika diperlukan, edit file JavaScript pada folder `assets/js/` untuk menambahkan animasi, efek scroll, atau validasi form.
